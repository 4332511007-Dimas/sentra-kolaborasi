## Konvensi Penamaan Branch
Konvensi Penamaan Branch
Format: awalan/deskripsi-singkat (huruf kecil, kata dipisah tanda hubung)

| Awalan  | Digunakan untuk                        | Contoh                    |
|---------|----------------------------------------|---------------------------|
| feat/   | Fitur atau kemampuan baru                | feat/tambah-healthcheck |
| fix/    | Perbaikan kesalahan                      | fix/port-bentrok        |
| docs/   | Perubahan dokumentasi                    | docs/panduan-instalasi  |
| chore/  | Pemeliharaan tanpa mengubah perilaku     | chore/rapikan-gitignore |
| hotfix/ | Perbaikan mendesak pada kondisi produksi | hotfix/gagal-start      |
